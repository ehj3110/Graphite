# Graphite Interlinked: The Friendly Guide to 3D Printing Chainmail & Metamaterials

Welcome to **Graphite Interlinked**. This guide is designed for designers, engineers, and makers who want to create **3D printable, print-in-place chainmail textiles and flexible compliant lattices** without needing to understand crystallography, Wyckoff symmetry positions, or catenation mathematics.

---

## 1. What Are Interlinked Metamaterials?

Standard 3D printed lattices weld intersecting struts together into rigid trusses.

**Interlinked metamaterials**, by contrast, consist of **separate, un-welded bodies** that physically thread through and hook around each other:
- When printing is complete, the individual links or cages move freely.
- The result is flexible fabric (like medieval chainmail or NASA space fabric) or compressible 3D cushioning blocks that absorb impacts through kinematics rather than material deformation alone.
- Every model generated by Graphite maintains **strictly positive clearance ($\Delta > 0$)** between adjacent bodies, preventing parts from fusing into a solid lump.

```
       [ Ring A ] <==== gap ====> [ Ring B ]
            \                       /
             \==== Interlocked ==== /
```

## 2. Low Risk vs. High Risk Profiles

Every 3D printer has finite dimensional accuracy. Graphite provides two simple, pre-tested **Risk Profiles**:

| Profile | Strut Diameter | Clearance Gap | Best Suited For |
|---------|----------------|---------------|-----------------|
| **`"low_risk"`** *(Default)* | **$1.0\,\text{mm}$** ($1000\,\mu\text{m}$) | **$0.20\,\text{mm}$** ($200\,\mu\text{m}$) | **High reliability, robust parts.** Recommended for almost all resin (SLA) and powder-bed (SLS/MJF) machines. Links withstand washing and handling easily. |
| **`"high_risk"`** | **$0.75\,\text{mm}$** ($750\,\mu\text{m}$) | **$0.15\,\text{mm}$** ($150\,\mu\text{m}$) | **Fine detail, lightweight.** For finely tuned machines with minimal light bleed. Produces tighter joints and smaller, lighter cages. |

You can also pass custom `strut_diameter` and `clearance` values at any time.

## 3. The 4 Primary Presets

| Preset Name | Type | Application | What It Looks Like |
|-------------|------|-------------|--------------------|
| **`chainmail`** | 2D Sheet | Flexible maille cloth, protective armor, draped covers | Alternating angled rings ($\pm 28^\circ$) woven in the classic European 4-in-1 maille pattern. |
| **`space_fabric`** | 2D Sheet | Space fabrics, rigid-tile flexible sheets, thermal shields | Hexagonal tiles with 6-fold spiral interlocking arms (NASA JPL style). |
| **`shock_absorber`** | 3D Block | Energy-absorbing cushions, shoe midsoles, impact damping | Bipartite diamond cubic tetrahedral cages (Zhou et al., *Science* 2025). |
| **`impact_cushion`** | 3D Block | High-clearance impact damping, compression blocks | Truncated tetrahedra arranged on a simple cubic grid with 6-fold face catenation. |

## 4. One-Line Python Recipes

You can generate and export complete assemblies in a single line of Python:

### A. Flexible Chainmail Fabric
```python
from graphite.explicit.interlinked import chainmail

# Generate a 60 x 60 mm chainmail sheet and save directly to 3MF
chainmail(width=60, length=60, export_path="outputs/chainmail.3mf")
```

### B. NASA Space Fabric
```python
from graphite.explicit.interlinked import space_fabric

# Generate an 80 x 80 mm space fabric sheet
space_fabric(width=80, length=80, export_path="outputs/space_fabric.3mf")
```

### C. 3D Shock Absorber Block
```python
from graphite.explicit.interlinked import shock_absorber

# Generate a 40 x 40 x 40 mm shock absorbing cubic block
shock_absorber(size=40, export_path="outputs/shock_absorber.3mf")
```

### D. Using High-Risk Profile for Fine Features
```python
from graphite.explicit.interlinked import shock_absorber

# High-risk profile: 0.75 mm struts, 150 um clearance
shock_absorber(size=(50, 50, 25), profile="high_risk", export_path="outputs/fine_cushion.3mf")
```

## 5. Universal Generator (`quick_lattice`)

For maximum flexibility, `quick_lattice` accepts any preset, cell name, or colloquial nickname:

```python
from graphite.explicit.interlinked import quick_lattice

# Use nicknames: "chainmail", "space", "shock", "cushion", "cubes", "octahedra"
result = quick_lattice("shock", size=45, profile="low_risk")

# Inspect the design
print(result.summary())

# Export as compact instanced 3MF or monolithic STL
result.export("outputs/lattice.3mf")
result.export("outputs/lattice.stl")
```

### Adding a Solid Perimeter Border (Policy C)
Need solid borders to grip the lattice in a tensile test or bolt it to a frame? Pass `add_frame=True`:
```python
result = quick_lattice("shock", size=40, add_frame=True, export_path="outputs/framed_lattice.3mf")
```

## 7. 3D Printing & Slicing Best Practices

### Stereolithography (SLA / Resin)
1. **Clearance:** Use the **Low Risk** profile ($200\,\mu\text{m}$) for your first test print. If your resin has low viscosity and low light bleed, you can step up to **High Risk** ($150\,\mu\text{m}$).
2. **Resin Wash:** Wash thoroughly in an ultrasonic bath or agitated IPA station (e.g. Form Wash) for 10–15 minutes. Un-cured resin trapped in the gaps can cure during UV post-curing and fuse the links together!
3. **UV Post-Curing:** Cure the lattice while submerged in water or glycerin to eliminate oxygen inhibition and ensure uniform surface tack-free hardness.

### Selective Laser Sintering (SLS / MJF / Powder)
1. **De-caking:** All 4 primary presets feature open polygonal apertures. Use compressed air and glass-bead blasting to remove residual powder from between the links.
2. **Clearance:** The default **Low Risk** profile ($200\,\mu\text{m}$) works on fine SLS (e.g. Formlabs Fuse 1 at $110\,\mu\text{m}$ layer height). For standard production nylon, you can pass explicit clearance: `--clearance 0.40`.

### File Format: Why 3MF is Strongly Recommended
Always export to **`.3mf`** instead of `.stl`. 
Graphite implements **ISO/IEC 5165 instanced 3MF packaging**, where each cage or ring prototype is written only once, and spatial placements are recorded as transforms. A 3MF file with 1,000 links is typically under **$100\,\text{KB}$**, whereas an equivalent STL file would be over **$100\,\text{MB}$**. Modern slicers (PrusaSlicer, Bambu Studio, OrcaSlicer, PreForm) natively support instanced 3MF.
